# YCA-003 — 通过 PowerShell 管理普通文件和目录

**What to build:** 艾米莉亚能通过 YCA 创建和查看目录，复制、移动、重命名及按要求删除普通文件和含文件的目录；PDF、Word、图片等二进制格式同样可管理。

**Blocked by:** YCA-001 — 真实 PowerShell 短脚本闭环与完整结果；复用其通用执行与结果契约。

**Status:** ready-for-agent — 票据范围与验收标准已审阅；实施仍遵守技术依赖及 ticket-design 建议，未授权批量实施，验收待执行。

**Spec:** [已审阅规范](../../specs/yuki-computer-agent.md)；User Stories 9、12～13、16、33；A2 文件管理条款；A2-AC1 的目录部分、AC2、AC3、AC8，别名见[索引](README.md)。

## 范围与明确不做

- 优先通过已交付的通用 PowerShell 完成普通文件与目录管理，并以真实验收、回归和操作说明形成可用成果。代码无缺口时允许不新增生产接口。
- 按任务目标处理复制、移动、重命名和删除；使用普通文本及二进制样本证明操作不受正文格式限制。保留已有专用文件工具行为，不用新通用用法偷偷改变旧接口。
- 不为各个文件子命令机械新增工具，不做 PDF/Word 正文提取、图片理解、专用文本读取重建、长任务或文件同步平台。

## 验收标准

- [ ] A2-AC1：经公开 MCP 创建并查看带中文/空格名称的目录，目录状态与实际磁盘一致。
- [ ] A2-AC2：在验收目录内对文件和含文件的目录完成复制、移动、重命名和明确要求的删除；核对源/目标存在性及预期内容。
- [ ] A2-AC3：包含普通二进制样本，复制/移动/重命名前后字节数与哈希一致，不因 PDF/Word/图片等格式而拒绝文件管理。
- [ ] 目标冲突、缺失源或系统拒绝等代表失败有可核对输出和退出结果，不无条件重试或宣称部分完成即全部成功。
- [ ] 现有专用接口的不覆盖用法保持兼容；通用脚本的行为由明确任务与所用命令决定，文档不混淆两者。
- [ ] A2-AC8：经 ChatGPT → YCA 复现文件/目录管理场景，全程不调用 Codex 模型；没有任何 B 阶段前置要求。

## 可复现验收方式

1. 在独立验收目录准备文本与无敏感内容二进制夹具、含夹具的子目录。通过 A1 通用执行完成各项操作，保存前后目录清单和文件哈希。
2. 对移动/重命名检查旧名消失及新名保留内容，对复制检查两份内容相等，对明确删除检查目标消失。递归操作前核实目标落在验收目录内。
3. 用受控冲突/缺失源案例检查失败反馈，避免测试覆盖或删除真实资料；补充公开 MCP 行为测试及可复用操作示例。
4. 经 ChatGPT 和原连接复现代表场景。如果 A1 已满足所有功能，交付新增验收与用法文档即可，无需包装额外工具。

## 随交付更新的文档

补充目录及普通文件操作示例、结果核对方法和冲突反馈；明确“可管理二进制文件”与“暂未提供正文解析”的区别，不写成禁止操作 PDF/Word/图片。

## ticket-design 建议

**不默认需要。** 先复用通用 PowerShell；本票的主要成果可以是可重复的能力验收与文档。仅在发现现有执行契约确实无法完成本票验收、需要改变外部行为时，列出具体缺口再建议局部设计。
